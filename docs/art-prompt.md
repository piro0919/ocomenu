# アイコンの依頼文

ChatGPT に投げる。Hawky と同じくモチーフ型で、人物は描かない。2026-09-30 に本人が決めた。
作り直すときはここから始める。

## 1通目

```text
macOS のアプリアイコンの原画を1枚、画像で生成してください。

アプリ名は Ocomenu。Mac の Finder の右クリックメニューを、自分で選んだ項目だけの短いメニューに置き換えるアプリです。「要らない項目を抜き取って、メニューを短くする」がモチーフです。

- 形式: 正方形 1024×1024。背景は四隅まで塗り切った正方形にしてください。角丸は付けないでください（こちらで付けます）。透明な部分は作らないでください
- 主役: 白い、縦長の角丸の板を1枚。右クリックで出るメニューの形です。板の中に、太くて短い横棒が3本、等間隔に並んでいます。棒の色は背景と同じ系統の濃い色
- 動き: 真ん中の1本だけが板から右へ半分ほど抜き出されて、斜めに少し傾いています。抜けた跡の場所は空いたままにしてください
- 画風: フラットなベクター風。白い面に、ごく淡い陰影だけ。細い線や細かい描き込みはしない。太い面で形を取る
- 背景: 左上の明るいミントグリーン（#3DD6B0 前後）から、右下の深い青緑（#12707F 前後）への滑らかなグラデーション
- 余白: 板と抜けた棒の全体が、外周15〜20%の余白の内側に収まるように。どこも端で切らない
- 文字、ロゴ、マウスのカーソル、枠、床の影などは一切入れない
- 要素は板・3本の棒・背景だけ

16px まで小さくしても「メニューから1行抜けている」と分かることが一番大事です。
```

返ってきた絵は、32px までは読めたが、抜き出した棒が細く斜めでペンに見え、16px では抜けた跡が分からなかった。

## 2通目

```text
方向はとても良いです。ただ 16px と 32px に縮めると、抜き出した棒がペンのように見え、抜けた跡も分かりません。次の点だけ直して、もう1枚生成してください。背景のグラデーションと画風はこのままで。

- 3本の棒を今の2倍くらいの太さにする。棒の両端は丸く
- 抜き出す真ん中の1本は、傾けずに水平のまま、板の右の縁から棒の長さの半分ほど外へ突き出させる。細くしない。ほかの2本と同じ太さと長さ
- 抜き出す棒だけ色を変える。背景の青緑と反対の、明るいコーラル（#FF7A59 前後）で塗る。ほかの2本は今の濃い青緑のまま
- 板の中の、抜けた棒が元あった場所は空けておく
- 板は少し横幅を広げ、板と突き出た棒の全体が、外周20%以上の余白の内側に収まるように
```

これを採った（1254×1254、透過なし）。16px でも、板・濃い2本・右へ突き出たコーラルの1本が分かる。

## 置き場所と確認

- 受け取った原画は `Resources/ocomenu-icon.png` に置く。`build.sh` が `.icns` を組み立てる
- 透過が一画素でも入っていると、macOS 26 は薄い板の上に載せて表示する。`sips -g hasAlpha` で `no` を確かめる
- 16px と 32px に縮めて、抜けた1本が見分けられるかを見る
